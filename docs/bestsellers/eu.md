## New category candidates

1. **LED light strips** (Govee, Philips Hue, WiZ, Tapo L900): Govee is heavily discounted across amazon.de listings (https://www.pcgameshardware.de/Smart-Home-Hardware-262218/). Compatibility is a real question (Matter, Alexa, Google, HomeKit, HA). Facts: `colorType`, `lengthMeters`, `lumens`, `controllerPower`. Uses the bulb schema nearly as is. Top 5 EU first picks unconfirmed; start with Govee Matter strips, Hue Lightstrip Plus, Tapo L930, WiZ strip, Nanoleaf Essentials. Evidence is weak: no ranking list surfaced.
2. **Smart blinds and curtain motors** (SwitchBot Curtain 3 / Blind Tilt, IKEA FYRTUR/PRAKTLYSING, Aqara Curtain E1, Shelly shutter relays): large home-automation demand in Spain, DE; "does it work with Apple Home / Alexa" is a core purchase question. Facts: `motorType` (curtain / roller / blind-tilt), `power`, `travelLimit`, `fit`. Evidence URL: https://gminsights.com/industry-analysis/europe-smart-home-market/market-analysis (market-level only). Picks per market unconfirmed.
3. Smoke and CO alarms (Netatmo, Nest Protect EU gone): lower fit, ranked third. Smart speakers/displays: already partly in hubs; not recommended.

Recommend: LED strips (cheapest, reuses bulb code), then curtain motors.
